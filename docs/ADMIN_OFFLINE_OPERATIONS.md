# Operasional Admin Kelas Offline

Admin memiliki tiga area utama yang menggantikan kontrol live learning dan progress online.

## Jadwal Kelas

Admin dapat memfilter, membuat, mengubah, membatalkan, dan mengekspor sesi. Form jadwal berisi kelas, waktu, venue, alamat, ruangan, peta, kapasitas, status, serta catatan persiapan.

## Kehadiran Peserta

Halaman kehadiran merangkum kelas yang terdaftar, sesi yang dipesan, hadir, tidak hadir, jadwal mendatang, dan attendance rate per anak. Detail peserta menampilkan status per kelas dan riwayat booking.

## Statistik

Statistik engagement memakai jumlah class session, booking, attendance, dan tingkat keterisian kelas. Funnel utama bergerak dari profil anak ke enrollment, booking, kehadiran, dan sertifikat.
